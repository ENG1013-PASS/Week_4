This folder contains code for a Pokemon battling game.
Most of the game code has already been completed but your job is to complete the attack and defend functions of your Pokemon.



Form groups of 2-5 people and pick a Pokemon from the list.
Please note that you may only select Pokemon in the order of the following list.
For example, if you have 3 members, you can only select from Pikachu, Bulbasaur and Charmander.

pokemonNames = ["Pikachu", "Bulbasaur", "Charmander", "Squirtle", "Mewtwo"]


Steps:
1. Each person will complete their Pokemon's abilities by completing the steps in their Pokemon's file.
2. Once complete, choose one person's laptop to run the game.
3. Share your Pokemon's code to that laptop via email or other method.
4. Do not touch any of the code in game.py or config.py
5. Run game.py
6. Enjoy and have fun!



Each round a random Pokemon will be chosen to attack and another to defend.
If your attack code is correct, a random attack value will be chosen.
If your defense is correct, you will only receive half damage.
This repeats until the last Pokemon standing.


Protip: You can each download the Live Share extension by Microsoft to work on code collaboratively like Google Docs (might be helpful for your projects)

Challenges:
1. Discuss with your team what each section of the game engine code does (Hint: a lot of the code is for aesthetics)
2. Try editing the game.py file to change the maths when calculating the damage given or some other game logic
